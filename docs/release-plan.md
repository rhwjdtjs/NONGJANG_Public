# 개발·공개·펀딩 목표 계획

[문서 처음](../README.md) · [전체 잔여 범위](roadmap.md) · [현재 구현의 검증 범위](development-and-validation.md)

**계획 수립일: 2026-09-20.** 아래 월 범위는 현시점의 개발 추정치이며 확정 출시일이나 판매·완성 보장이 아닙니다. 이 문서 작성으로 상점 출시 예약, 펀딩 프로젝트 개설·심사 신청·오픈을 실행하지 않았습니다. 가격·펀딩 목표금액·선물 구성·전달일도 아직 확정하지 않았습니다.

## 일정의 전제

TEAMNIRIZ 1인 개발과 Codex 협업 기반을 유지합니다. SINGULARITY의 **2026년 말 데모·2027년 상반기 출시 목표와 병행**한다는 작업 배분을 가정해 NONGJANG의 2027년 상반기를 통합·회귀 기간으로 확보합니다. 다른 프로젝트의 목표 역시 확정 일정으로 취급하지 않으며 실제 투입 가능 시간과 결함 규모에 따라 이 계획을 갱신합니다.

내부 명세의 **24개 영역·160개 열린 완료 조건**을 그대로 유지합니다. 작업 크기와 의존성이 서로 다르므로 항목 수를 나눠 완성률·주당 처리량·출시일을 계산하지 않습니다. 코드 작성 속도만으로 에셋 연결, 실제 플레이 검수, 저장·멀티·장기 생태 시험 시간을 대체하지 않습니다.

현재 **실제 주간 투입 시간은 아직 측정하지 않았으므로 이 일정은 중장기 추정**입니다. 초기 **4~6주간 실제 투입 시간과 완료 조건 통과 기록**을 모아 첫 재산정을 하고, 이후 분기별로 다시 산정합니다. 접지·장비·VFX·저장 작업의 구현과 재검사 시간, 다시 열린 결함, 에셋 호환 문제, 병행 프로젝트의 실제 소요를 기록해 목표 창을 조정합니다. 이는 자체 일정 점검 주기이며 검사 개수나 현재 날짜만으로 미래 공개를 확약하는 근거가 아닙니다.

**공개 데모는 현재 요청한 기능 전체를 포함합니다.** 생태·모든 동물 유형·교감·훈련·생활·사냥·건설·차량·멀티·지도·UI와 전체 섬 제작을 일부만 만들고 데모 완료로 처리하지 않습니다. 참조 기반 경관, 물·날씨·VFX·음향·UI도 데모에서 이미 요청한 품질로 실제 플레이 검수를 통과해야 합니다. 기존에 별도 후속으로 정한 농사·작물 범위를 이 일정 때문에 임의로 바꾸지는 않습니다.

## 공개 데모·EA·1.0의 구분

| 단계 | 공통 기능 범위 | 단계에서 확인할 성숙도 |
|---|---|---|
| 공개 데모 | 요청한 전체 기능군과 전체 섬, 전 종, 교감·생활·제작·차량·2인 멀티·저장·UI·환경 표현 | 일반 이용자가 설치해 연속 플레이할 수 있는 품질, 주요 결함 해소와 실제 플레이 증거 |
| 얼리 액세스 | 데모의 전체 기능 범위를 유지 | 외부 피드백을 통한 콘텐츠 밀도·다양성·생태/경제/생존 균형의 발전, 운영·하드웨어·저장 호환의 반복 검수 |

이 구분으로 기능을 EA나 1.0까지 누락해도 된다고 해석하지 않습니다. EA에서 이용자 피드백으로 생태·생활의 경험을 실질적으로 발전시킬 계획이며, 모든 설계가 끝나고 버그 검사만 남은 상황이라면 EA 경로의 적합성을 다시 검토합니다. Steam은 EA에서 구매 시점의 플레이 가치를 제공하고 현재 상태와 향후 계획을 구분하도록 안내합니다. 미래 완성을 보장하는 판매 문구는 사용하지 않습니다. [Steam Early Access 공식 안내](https://partner.steamgames.com/doc/store/earlyaccess), 확인일 2026-09-20.

## 공개를 결정하는 실제 증거

다음은 **프로젝트 자체의 검수 계획**이며 Steam·텀블벅이 정한 시험 횟수나 공식 성능 인증 기준이 아닙니다. 현재 통과 결과를 의미하지 않습니다. 구체적인 시간·횟수·성능 예산은 시험 기기의 사양과 시나리오를 고정한 뒤 정하고 결과와 함께 공개합니다.

| 확인할 조건 | 남길 근거 |
|---|---|
| 전체 기능과 세계 연결 | F01~F24와 연결된 실제 플레이 시나리오, 전체 섬의 이동·생활·교감·사냥·건축·차량 동선 |
| 전 종과 생태의 지속 | 종별 욕구·공격/도주·교감/명령·사육 조건, 원근 전환과 여러 게임 날짜에 걸친 자원·개체군 회귀 |
| 두 사람의 실제 플레이 | 다른 물리 PC 두 대와 Steam 계정 두 개의 교역소 입장·방문·귀환, 지연·손실·재접속·호스트/방문자 상태 확인 |
| 저장과 복구 | 새 프로세스의 이어하기, 사망·새 생명, 물품·동물·관계·차량·트렁크 상태, 중복 지급·유실 방지와 장애 복구 |
| 접지·장비·전투/생활 연출 | 수면·사망·평지/경사·각 자세의 발/몸 접지, 무기/가방 관통, 총구 발생점·방향, 물/흙/먼지·불과 실제 음향 |
| 요청한 월드 표현과 조작 | 참조 기반 전체 경관·재질·물·날씨·조명, 최종 사용 UI, 키마/패드, 옵션 실제 적용·저장 |
| 실제 성능과 실행물 | 해상도·옵션·DLSS 상태·PC 사양을 밝힌 프레임/메모리/끊김 기록, 에디터가 없는 환경에서 설치·실행되는 Windows 빌드 |
| 공개 설명과 화면 | 현재 후보 빌드에서 직접 촬영한 영상·화면·음향과 버전, 알려진 문제, 기능 설명의 일치 |

공개 문서, 자동 검사 수, 소스 코드, 목표 화면을 시각화한 생성 이미지는 실제 실행 빌드와 현재 게임 촬영을 대신하지 않습니다. 저장 손상·물품 복제/유실·진행 차단·반복 충돌처럼 공개를 막는 결함이 남으면 비공개 상태를 유지합니다.

## Steam 데모·EA 준비

NONGJANG 자체 제품과 연결된 데모를 준비하고 체크리스트·빌드 심사를 완료한 뒤 공개합니다. 본편 출시 전 데모라면 본편의 Coming Soon 페이지와 연결을 확인하고, 데모 공개 후 본편 페이지의 다운로드 버튼 노출까지 재확인합니다. [Steam Demos 공식 안내](https://partner.steamgames.com/doc/store/application/demos), 확인일 2026-09-20.

상점 설명에는 실제 후보 빌드에 있는 기능을 적고 상점과 빌드 검토를 각각 준비합니다. 공식 안내의 상점 검토는 통상 3~5영업일이며 희망 공개일 최소 7일 전 제출을 권장하므로, 내부 일정에는 보완 여유를 더 확보합니다. 이는 승인 기한 보장이 아닙니다. [Steam 출시 절차](https://partner.steamgames.com/doc/store/releasing), 확인일 2026-09-20.

EA를 선택할 때는 현재 플레이 가능 범위, 남은 개선, 예상 기간, 가격 방침, 이용자 참여 방식과 저장 호환 계획을 Q&A에 작성합니다. 향후 판매량만으로 완성을 전제하지 않고 현재 빌드의 가치와 가용 개발 계획을 검토합니다. [Steam Early Access 공식 안내](https://partner.steamgames.com/doc/store/earlyaccess), 확인일 2026-09-20.

## 텀블벅 준비와 진행

**펀딩 목표 창은 2028년 2월~3월 초, 약 4주**입니다. 공개 데모가 계획대로 나왔다는 전제의 후보 일정이며, 실제 배포 후 2~4주간 문의 대응·피드백 반영과 안정화가 확인되고 심사까지 승인돼야 오픈합니다. 이 기간은 자체 운영 계획이며 플랫폼이 정한 의무 대기 기간이 아닙니다.

### 원고·견적·선물

1. 현재 빌드에서 촬영한 플레이 영상과 기능 설명, 개발 이력·남은 작업·위험 요인을 준비합니다. 생성 이미지를 실제 게임 증거로 사용하지 않습니다.
2. 잔여 개발 노동, QA·시험 기기, 필요한 외주·라이선스·현지화, 지원·운영, 수수료·세금·정산 시차와 예비비를 견적 냅니다. 목표금액은 검증된 비용과 가용 자금을 대조한 후 정합니다.
3. 관리 부담이 낮은 **디지털 선물을 우선 검토**합니다. 개발 기록·디지털 자료·크레딧 등도 제작 가능성과 권리를 확인한 뒤 구성하며, 게임 이용권·Steam 키·참여 혜택은 전달 가능성과 플랫폼 조건 확인 전 확정하지 않습니다. 실물 배송이나 새 게임 기능을 약속하는 확장 목표를 임의로 추가하지 않습니다.
4. 펀딩 시작·마감, 결제 확인, 정산, 선물 제작·전달을 별도 일정으로 작성합니다. **펀딩 마감일을 정산 완료일로 간주하지 않습니다.** 선물 전달일과 지연·취소 대응 문안은 실제 준비 상태와 당시 적용 정책을 확인한 뒤 확정합니다.
