# 데모와 출시 계획

[문서 처음](../README.md) · [남은 작업](roadmap.md) · [검증 범위](development-and-validation.md)

문서 기준일: 2026-10-01. 2026-09-20에 세운 목표는 **공개 데모 2027년 1~2월, Steam 얼리 액세스 2027년 3월**입니다. 정식 1.0 일정은 미정입니다. 현재 통합·패키지 검수 전이므로 확정 출시일로 안내하지 않습니다.

## 목표 일정

| 목표 시기 | 작업 | 확인할 결과 |
|---|---|---|
| 2026년 10월 | 접지·수면·사망·장비·총구·노면 효과와 저장 결함 수정, 생존·생태·교감 흐름 | 같은 조건에서 재현·수정·재검사, 시작부터 저장·복원까지 연결 |
| 2026년 11월 | 전체 기능군, 차량·트렁크·운반·정식판 2인 멀티, 월드·그래픽·물·날씨·음향·UI 통합 | 한 섬과 실행 빌드에서 상태·물품·개체·관계가 함께 동작 |
| 2026년 12월 | 전 종·두 PC Steam·저장 장애·장기 생태·성능·입력·Windows 패키지 검수, 외부 소규모 시험 | 설치 가능한 후보 빌드, 실제 플레이 기록과 남은 결함 목록 |
| 2027년 1~2월 | 공개 데모 목표, 제한 기능·플랫폼 제출·차단 결함 검수 | 이용자가 설치하고 싱글 플레이를 체험하는 빌드 |
| 2027년 3월 | Steam 얼리 액세스 목표, 데모 피드백·저장 호환·업데이트 준비 | 구매 시점의 기능과 상태를 설명할 수 있는 배포본 |
| 정식 1.0 | 일정 미정, EA 결과로 판단 | 최종 요구·장기 균형·안정성과 유지보수 검수 |

월별 표는 집중 작업과 점검 시점입니다. 선행 조건이 갖춰지면 작업을 병행하고 결함 수정·재검수 시간도 포함합니다.

## 데모 설계

2026-09-27에 확정한 요구입니다. **명세 반영은 완료했고 구현·검수는 대기 중입니다.** 기존 기능을 연결한 뒤 데모 출시 직전에 적용합니다.

| 항목 | 요구사항 |
|---|---|
| 이용 시간 | 현실 플레이 1시간을 게임 1일로 계산해 최대 게임 3일·누적 3시간 체험 |
| 저장 | 사용자에게 제공하는 저장 슬롯 1개. 내부 복구용 백업은 별도 플레이 슬롯으로 노출하지 않음 |
| 이용 기록 | Steam 계정과 기기의 누적 시간·만료를 유지. 어느 한쪽이 만료돼도 플레이 차단 |
| 재실행·재설치 | 새 게임·세이브 삭제·재설치로 시간 초기화 불가. 같은 PC의 Windows·Steam 계정 변경도 검수 |
| 멀티 | 싱글 전용. 초대·생성·검색·참가·LAN·직접 주소 접속 등 진입 경로 차단 |
| 만료 | “데모 플레이 해주셔서 감사합니다.” 안내, 위시리스트 이동과 종료 버튼. 만료 후 실행에도 월드 진입 전 확인 |

계정·기기 기록은 서버가 확인하는 설계를 기본안으로 둡니다. 오프라인 허용과 통신 장애 유예, 기기 식별 방식·오탐·변경 대응, 수면·일시정지 등의 시간 정책은 구현 전에 정해야 합니다. OS 재설치와 하드웨어 교체까지 같은 기기를 영구적으로 식별한다는 보장은 하지 않습니다.

기존 공개 문서의 멀티를 포함한 전체 기능 데모 설명은 이 설계로 갱신합니다. 정식판은 최대 2인 교역소 방문을 계속 개발하며 데모 배포에만 싱글·시간·슬롯 제한을 적용합니다. 게임 전체의 기능 요구는 [남은 작업](roadmap.md)에서 유지합니다.

## 공개 전 확인할 조건

1. 에디터 없는 PC에서 설치·실행하고 실제 섬의 새 게임, 생존·정착·교감·사냥·제작, 사망·새 생명과 이어하기를 확인합니다.
2. 신규 총기·운반·차량·관계·물품을 저장·복원하며 강제 종료와 손상 복구를 검수합니다. 정식판 멀티는 두 PC·Steam 두 계정의 방문·귀환·지연·중단·재접속으로 확인합니다.
3. 전 종의 행동·교감·명령·사육, 전체 경관·물·날씨·소리·이펙트·UI·입력을 같은 빌드에서 확인합니다. 접지·장비 관통과 총구 위치도 실제 화면으로 검수합니다.
4. 여러 게임 날짜의 생태·자원, 원근 전환·스트리밍·메모리·저장 반복을 시험하고 PC 사양·해상도·옵션·DLSS 상태를 함께 기록합니다.
5. 데모의 시간·슬롯·만료·싱글 제한을 실제 패키지에서 확인합니다. 재실행·삭제·재설치·계정 변경, 강제 종료·시계 변경·서버 장애로 이용 시간이 초기화되지 않는지도 검수합니다.
6. EA 전에는 데모 피드백과 차단 결함을 반영하고 현재 제공 기능, 저장 호환·업데이트·제보·복구 경로를 준비합니다.

현재 위 조건의 전체 통과를 주장하지 않습니다. 공개를 막는 결함이 남으면 비공개 시험을 이어가고 목표를 조정합니다. 데모가 늦어지면 EA까지의 피드백·안정화 기간도 다시 판단합니다.

## 제출과 안내

현재 빌드에서 촬영한 자료, 제공 기능·설치·조작 안내와 알려진 문제를 준비합니다. 플랫폼 요구사항은 실제 제출 시점의 [Steam 데모](https://partner.steamgames.com/doc/store/application/demos), [출시 절차](https://partner.steamgames.com/doc/store/releasing), [Early Access](https://partner.steamgames.com/doc/store/earlyaccess) 안내로 다시 확인합니다.

[Discord](https://discord.gg/uXfjXmnd68)와 공개 문서·웹·Steam에는 실제 변경과 피드백 반영을 안내합니다. 일정이 바뀌면 이유와 영향, 다음 점검 기준을 함께 갱신합니다.
