# 출시까지 남은 작업

[문서 처음](../README.md) · [현재 검증 범위](development-and-validation.md) · [목표 개발·공개 일정](release-plan.md)

**2026-09-20 기준: 부분 구현·통합 중.** 내부 최종 빌드 명세에는 **24개 영역, 160개 열린 완료 조건**이 있습니다. 아래는 같은 범위를 읽기 쉽게 요약한 것입니다. 영역별 기반이나 일부 시험이 있어도 모든 조건을 충족하기 전에는 영역 전체를 완료 처리하지 않습니다.

[개발·데모·출시 계획](release-plan.md)은 이 범위를 유지한 목표 일정입니다. **공개 데모부터 요청한 전체 기능이 실제로 플레이 가능해야 하며**, 전체 섬·경관·물·날씨·효과·음향·UI도 포함합니다. 일정에 맞추려고 일부 기능군을 제외하지 않습니다. 미충족 상태에서는 비공개 테스트를 유지하고 후속 일정을 순연합니다. 160개 항목은 크기와 의존성이 달라 단순 개수로 완성률이나 소요 기간을 계산하지 않습니다.

## 특히 별도 완료 증거가 필요한 항목

- **샷건 총구와 Niagara:** 좌표 설정뿐 아니라 보이는 총구와 입자 시작점·방향을 같은 발사 프레임에서 비교. 자세·이동·상하 조준·호스트/방문자 조건 포함.
- **접지와 장비:** 수면·사망 때 발과 몸의 부유·관통, 의상 조합과 움직임에서 무기·가방의 부착 확인.
- **자연 생태:** 일부 종의 섭식·교감 검수에서 전 종의 사회 행동·사육·장기 생태 균형으로 확장.
- **멀티와 저장:** 같은 PC의 제한된 LAN 시나리오에서 실제 두 PC·Steam 계정·지연·장애·새 기능 통합으로 확장.
- **최종 경관과 배포:** 목표 이미지를 실제 월드 구현 증거로 사용하지 않고 실제 실행 화면·음향·성능·패키지로 확인.

목표 월 범위는 [일정 문서](release-plan.md)에 공개하되 확정 출시일이나 완료 보장으로 제시하지 않습니다. 데모·얼리 액세스·1.0의 단계 차이는 기능군 누락이 아니라 콘텐츠 깊이·다양성·장기 균형·안정성·최종 마감과 유지보수 검수의 성숙도입니다. 공개 문서·포트폴리오의 완성은 위 게임 구현 조건의 완료와 별도로 관리합니다.
