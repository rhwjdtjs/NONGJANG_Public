## Codex와 Claude 활용

TEAMNIRIZ의 1인 프로젝트로 기획과 요구사항, 작업 우선순위를 정하고 Codex와 Claude를 함께 사용합니다. C++ 구현과 에셋 연결, 자동 검사, 실제 화면 검수 도구를 작업하며 실패한 실행과 남은 결함을 인계 문서에 남깁니다.

9월 말에는 Codex의 월드·캐릭터 작업에 이어 Claude가 무기 파지와 보행, 총기·운반·차량·동물 행동을 수정했습니다. 이후 Codex가 월드·그래픽 후보를 이어서 검수하고 있습니다. 모델이 작성한 코드, 외부 에셋 활용, 실제 게임에서 확인한 동작을 구분해 기록합니다.

종별 DataAsset, 설정·JSON, 역할별 C++ 파일과 에디터 저작 도구로 수정 경로를 나눕니다. 편집 설명서와 최종 유지보수 문서도 함께 정리하고 있습니다.

## 검사 방법

| 방법 | 확인하는 내용 | 추가로 확인할 범위 |
|---|---|---|
| 소스 읽기 | 상태·분기·저장·표현의 연결 | 실제 실행과 화면 품질 |
| 자동 검사 | 정해진 입력에서 규칙과 상태 유지 | 전체 장면·연속 플레이 |
| 실제 엔진 화면 | 파지·접지·메시·UI와 장면 구성 | 시간에 따른 흐름, 저장·네트워크 |
| 새 프로세스 재실행 | 메모리에 남은 값에 의존하지 않고 복원 | 강제 종료·전원 차단·손상 복구 |
| 독립 프로세스 LAN | 연결·RPC·방문·귀환 경로 | 실제 두 PC·Steam 두 계정·출시 빌드 |

월드 후보는 저장 전 검사, 실제 화면 비교, 채택 판정을 나눕니다. 그림이 부자연스럽거나 접지 문제가 발견되면 후보를 보류하거나 원본을 복원합니다. 식생 수량과 저장 성공만으로 최종 경관을 완료 처리하지 않습니다.

## 결함 수정 사례

먹이를 받던 돼지가 계속 회전해 손·입 접촉을 놓쳤습니다. 교감 예약에서 회전도 정리한 뒤 먹이 소비·취소와 재실행 복원을 다시 확인했습니다.

차량은 물리 몸체가 이동해도 외부 아트가 스폰 위치에 남는 문제가 있었습니다. 아트 컴포넌트의 Static 모빌리티를 확인해 런타임 추종을 수정하고 실제 주행 화면으로 재검수했습니다. 운전자의 앉은 자세가 없어 발이 차체 아래로 보이는 문제가 있었습니다. 현재는 탑승 중 운전자를 숨기는 임시 처리로 남아 있습니다.

월드 작업에서는 나무 바람, 풀의 반복, 밝은 빈 바닥, 동굴 형태와 뿌리 부유를 따로 확인합니다. 10월 1일 해안 표면과 목본 군락의 첫 후보는 실제 화면에서 각각 평평한 표면과 부유 뿌리가 보여 채택을 보류하고 원본을 복원했습니다. 후속 후보의 결과는 전체 경관 완료와 구분합니다.
