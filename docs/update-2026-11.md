# 2026년 11월 개발 기록

[문서 처음](../README.md), [검증 범위](development-and-validation.md), [데모 계획](release-plan.md)

기준일: 2026-11-02. 현재 소스와 10월~11월 인계, 검수 기록을 읽고 정리했습니다. 이번 문서 갱신에서는 새 빌드나 게임 실행을 하지 않았습니다.

## 생활과 정착을 연결하기

10월 초에는 통나무 건축에 2층 바닥, 계단, 가구, 램프를 더하고 지은 바닥 위에 침대와 보관함을 놓는 흐름을 검수했습니다. 높은 울타리와 문, 여물통 먹이, 물 공급도 연결했습니다. 같은 PC의 2개 게임 프로세스에서는 방문자가 설치한 울타리가 양쪽에 복제되는 경로를 확인했습니다. 이 기록은 실제 두 PC의 Steam 검수를 대신하지 않습니다.

사망 후에는 몸의 물품 처리를 마치고 새 생명을 시작하되 세계, 집, 보관함을 유지하는 흐름을 추가했습니다. 방문자 사망과 호스트 사망의 귀환, 대기 조건도 나눠 검사했습니다. 이후 변경을 포함한 전체 생존 흐름은 같은 출시 후보에서 다시 확인해야 합니다.

## 무기 동작을 실제 캐릭터로 확인하기

무기 파지와 장전은 뼈나 소켓의 수치가 맞는지에 더해 표시 캐릭터의 손, 팔, 의복을 함께 봅니다. Animation Blueprint와 원본 애니메이션, 후처리에서 처음 어긋나는 단계를 찾아 수정 후보를 분리합니다. 접촉에 실패한 후보는 채택하지 않고 기록을 남깁니다.

11월 1일에는 특정 여성 캐릭터와 후디, 매그넘, 호환 장비를 사용한 독립 실행에서 제작, 장착, 꺼내기, 조준, 장전, 집어넣기를 확인했습니다. 아래를 보는 상태의 이동, 반복 동작과 중단 후 복귀도 해당 조건에서 검사했습니다. 같은 기록의 애니메이션, 운반 검사 9개가 성공했습니다. 앞선 범용 총기 시험의 기존 실패 2개는 별도로 남아 있어 전체 자동 검사가 무실패라고 쓰지 않습니다.

이 결과는 해당 캐릭터와 장비 조건의 검수입니다. 다른 캐릭터, 착장, 모든 자세, 네트워크와 전체 피부 접촉까지 승인한 것은 아닙니다. 첫 동작의 프레임 취득 간격이 벌어진 구간도 있어 연속 24fps 전수 증거로 사용하지 않습니다. 권총은 팔꿈치, 의복 관통과 손가락 파지 문제를 확인해 후속 수정 중입니다.

## 차량에서 일반 자세로 돌아오기

차량에서는 발을 다시 딛고 일반 대기 자세로 돌아오는 구간을 따로 조사했습니다. 원본 애니메이션의 발 목표, 정상 애니메이션 평가와 최종 표시 발 위치를 같은 프레임에서 비교해 보조 목표 키와 자세 인계의 차이를 좁혔습니다.

10월 27일 기록의 연속 화면에서는 선택한 차량 복귀 구간에 이전의 안쪽 발 점프와 뚜렷한 끌림이 보이지 않았습니다. 그래서 해당 구간을 수용했습니다. 현재는 선택적 검수 조건의 후보이며 기본 게임 전체 적용, 전체 승하차, 좌석, 다른 체형, 실제 월드 검수는 남아 있습니다. 권총과 일반 걷기의 일부 회귀 화면도 확인했지만 걷기 전체의 연속 동작 승인으로 확대하지 않습니다.

## 데모 정책 바로잡기

10월 23일 기준 데모 요구는 **싱글 플레이, 게임 속 생존 3일, 새 게임마다 다시 체험**입니다. 이어하기와 같은 세계의 새 생명은 남은 일수를 유지하고 수면으로 흐른 게임 시간도 포함합니다.

11월 2일 소스 대조에서 기존 `NNDemo`는 여전히 현실 시간과 계정, 기기 이용 기록을 사용하고 있습니다. 정책 문서는 새 기준으로 갱신했지만 구현 전환과 실제 데모 패키지 검수는 남아 있습니다. 구현된 구형 타이머, 만료 화면을 새 정책 완성으로 계산하지 않습니다.

## 저장, 멀티, 출시 검수

두 저장 세대를 번갈아 쓰고 읽기 검증하는 구조와 방문, 귀환 저널은 구현되어 있습니다. 세계 저장과 홈 목록을 하나의 원자적 파일 시스템 작업으로 처리한다고 보장하지는 않습니다. 저장 중 강제 종료와 손상 복구, 방문 중 물품 이동 직후 중단, 재접속은 추가 검수 범위입니다.

최대 2인 방문은 같은 PC의 독립 프로세스에서 개발 시나리오를 검사했습니다. 실제 두 PC, Steam 두 계정, 지연, 손실, 음성, 차량 동기화, 에디터 없는 PC의 Shipping 패키지와 장기 생태, 성능은 출시 전 확인해야 합니다.

공개 화면은 [미디어 안내](../media/README.md), 전체 과제는 [남은 작업](roadmap.md)에 연결했습니다. 문서에 적힌 파일명은 비공개 원본의 근거 식별자이며 원시 로그와 개인 저장은 공개하지 않습니다.
