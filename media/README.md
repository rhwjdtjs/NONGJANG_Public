모두 기존 개발본에서 촬영한 실제 게임 화면입니다. 공개용으로 WebP 변환과 해상도 축소만 했으며 화면 내용을 합성하거나 생성하지 않았습니다. 촬영 시점은 원본 자료의 기록을 따릅니다. 정지 화면을 기능 전체의 동작, 성능, 출시 품질 검수 증거로 해석하지 않습니다.

게임에는 외부 캐릭터, 동물, 환경 에셋을 활용합니다. 이 저장소는 게임 내 화면을 소개하며 원본 상용 자산은 배포하지 않습니다.
